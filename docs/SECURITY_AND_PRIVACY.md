# Security and privacy

The source checkout contains reusable code, synthetic tests and empty templates.
Private engagement data and private reusable knowledge belong outside it. Never
publish raw workspaces, customer identifiers, credentials, captured evidence, query
records, sensitive report exports, editor history or environment files.

The operator controls scope and exact authorization. Neither profile, restored
history, registered storage nor a model response grants authority. Built-in takeover
presets are absent. Managed workspaces retain versioned configuration reviews and
block legacy target-grant commands that cannot express their application boundaries.
Legacy exact authorization recording requires a review reference. These records do not authenticate
the operator; protect the runtime with OS access controls and team procedures.

Secret display is off unless separately enabled and acknowledged under a current
legacy policy. Managed workspaces supply no live legacy standing grant, so that
secret-display path remains unavailable. Plaintext report export has an additional explicit policy and acknowledgement
boundary. Profile changes do not turn either switch on. Unresolved session tokens
block closure and ordinary checkpoints in both profiles.

Read [ARTIFACT_HANDLING.md](ARTIFACT_HANDLING.md) before accepting target files.
No-download and remote-location registration are independent. The implementation
cannot enforce data placement in arbitrary external commands or truthfulness of
operator-supplied provenance. Do not retain target files in query logs or generated
containers to bypass the policy.

Same-user stream coordination provides integrity and concurrent writer control,
not multi-user isolation, SSO or RBAC. Keep independent operators in independently
protected runtimes. Perform reviewed, confidential handoffs through approved storage.

Release packaging uses an explicit source allowlist and rejects runtime paths,
personal home paths and legacy product markers. This reduces accidental inclusion;
source ownership and the contents of any newly added binary still require review.

Shared source and operator documentation must be in English. Release validation
also checks JSON-escaped editor paths and rejects cookie files and Polish text.
See [GitLab handoff](GITLAB_HANDOFF.md) for source-history and publication guidance.
