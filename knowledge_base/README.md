# Public Knowledge Base

This directory is the commit-eligible knowledge zone for Cyber-Operator. It contains
only generic, independently authored, redistribution-safe material. It is not a
mirror, export, or sanitized copy of `private_knowledge/` or any lab workspace.

Before adding an entry, confirm that it contains no credentials, target identifiers,
addresses, evidence, flags, customer or engagement data, proprietary course text, or
lab-specific reproduction details. Record its provenance class, scope, limitations,
and safe-validation or stop conditions. Link accepted entries from
[`indexes/README.md`](indexes/README.md).

Private knowledge stays outside the repository. Customer and other private
target-specific material stays in its private workspace regardless of whether the
operator may discuss or publish that platform elsewhere.
